# Record Display

PyQt5로 만든 간단한 Windows 화면 녹화 프로그램입니다.  
녹화할 모니터를 선택하고, F12 단축키로 녹화를 시작하거나 종료할 수 있습니다.

## 주요 기능

- 모니터 또는 전체 화면 선택 녹화
- F12 단축키로 녹화 시작/종료
- 저장 경로 직접 선택
- 예약 종료 시간 설정
- 녹화 영역을 빨간 테두리로 표시
- 빨간 테두리는 실제 녹화 영상에 포함되지 않도록 처리

## 실행 환경

- Windows
- Python 3.9 이상 권장

## 설치

```bash
pip install PyQt5 opencv-python numpy mss keyboard
```

## 실행

```bash
python main.py
```

## 사용 방법

1. `python main.py`로 프로그램을 실행합니다.
2. 저장 경로를 선택합니다. 기본 파일명은 `output.avi`입니다.
3. 녹화할 모니터 또는 전체 화면을 선택합니다.
4. 필요하면 예약 종료를 켜고 시간을 분 단위로 설정합니다.
5. `녹화 시작` 버튼 또는 `F12` 키로 녹화를 시작합니다.
6. 다시 `F12` 키를 누르거나 `녹화 종료` 버튼을 눌러 저장합니다.

## 참고 사항

- `keyboard` 라이브러리는 전역 단축키 등록을 위해 Windows에서 관리자 권한이 필요할 수 있습니다.
- 출력 영상은 AVI 형식으로 저장됩니다.
- 빨간 테두리는 사용자가 녹화 영역을 확인하기 위한 안내선이며, Windows 캡처 제외 API를 사용해 결과 영상에는 포함되지 않도록 설정되어 있습니다.
